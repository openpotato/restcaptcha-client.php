# RESTCaptcha PHP Client

The official [PHP](https://www.php.net/) client library for server-side access to the [RESTCaptcha API](https://github.com/openpotato/restcaptcha).

+ Supports PHP 8.3+
+ Supports the `verify` API endpoint for server-side verification.
+ Supports [RFC 9457](https://datatracker.ietf.org/doc/html/rfc9457) error responses
+ Uses [Guzzle](https://github.com/guzzle/guzzle) as HTTP client.

## Installation

The **RESTCaptcha PHP Client** is available on [Packagist](https://packagist.org/packages/openpotato/restcaptcha-client), and installation via [Composer](https://getcomposer.org/) is the recommended way to install:

``` bash
composer require openpotato/restcaptcha-client
```
